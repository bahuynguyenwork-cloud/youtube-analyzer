Google Sheets Apps Script

Code tự động lấy video & chuyển giờ đăng sang múi giờ VN

Cách sử dụng:

  1. Mở bảng tính Google Sheets mới.
  2. Vào menu Tiện ích mở rộng (Extensions) > Apps Script.
  3. Xóa code cũ, nhấn nút "Copy Toàn Bộ Code" bên dưới rồi Dán vào.
  4. Điền API_KEY và CHANNEL_ID của bạn vào đầu file rồi nhấn Lưu.
  5. F5 lại Google Sheet, chọn menu 🎬 YouTube > Lấy tất cả video!
